# GitHubAngularTypescriptMainApp

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 18.2.12.

## what is this project?

AngularTypescriptCleanMainApp project code provides angular/typescript UI implementation of basic CURD operation for book and person models
this project implementation angular service to make http call to external API for CURD operation

## important note

This project code base is only intended to learn angular/typescript programming and may be used for educational purposes.
